# 玩家功能输出模板 v1

设计稿使用虚构玩家和示例成绩，不表示已实现业务或已查询官方数据。HTML 为可编辑静态模板；头像首字母是资源缺失时的占位设计。预览通过项目 PlaywrightRenderer / PlaywrightBrowserProvider 和 RenderAttribution 生成，1200px 宽，自适应高度。

| 文件 | 信息层级 |
| --- | --- |
| weekly-report | 玩家、周期 → PP / 排名变化 → 游玩统计 → PP 曲线、代表成绩 |
| breakthrough-alert.txt | 纯文本：玩家、谱面 → PP、BP 位置与成绩 → 总 PP / 排名变化 |
| score-comparison | 谱面与比较条件 → 双方身份 → PP → 逐项指标 → 差异摘要 |

## 个人周报

使用配置时区的完整自然周，变化基线是周开始边界与结束边界的快照，不以本周第一条快照替代周开始边界。显示实际覆盖区间；缺少基线时变化显示“—”。无新 BP 显示空状态，不保留三条占位。榜单最多三条，完整榜单后续另页输出。

新增 BP 的 v1 口径：本周发生且周期结束时仍位于前 100 的成绩。相同谱面/Mods 的旧成绩被替换不重复列为两条。游玩次数、时长取资料快照差值；活跃天数需要完整每日快照，缺失时为“—”。曲线应来自实际快照，缺口断开。模板数值与曲线仅为布局示意。

## 新 BP / 排名突破提醒

纯文本输出，不再生成提醒图片。新 BP 包含玩家、谱面与 Mods、单曲 PP、BP 位置和成绩摘要；排名突破包含前后排名、提升名次与里程碑。两个事件同时发生时合并一条文本。仅排名事件省略谱面成绩。缺少可靠前值时省略差值，不虚构首次突破；PP 与排名变化属于观测区间，不能直接归因于单条成绩。缺失字段省略或显示“—”。

## 同图成绩对比

默认两位玩家、同一谱面、同模式、同 Mods 设置、同客户端与计分口径。条件不一致时顶部明确列出差异，收起“相同游玩条件”标签与优胜高亮，不生成统一胜负判断。差值说明方向；Acc 差值单位是百分点。判定组合不整体标记优劣。

Standard 展示 300 / 100 / 50 / Miss；Taiko、Catch、Mania 后续需要替换为各自判定与相关指标，不套用 Standard 字段。缺失成绩用该侧空状态，不用 0 替代。

## 布局与后续验收

本版完成正常 Standard 示例的实际 PNG 输出和溢出检查，尚未完成四模式、长名称、缺失成绩、无 BP 等边界样本的业务模板验收。长玩家名和难度标题应允许换行并增高；不压缩数字字号。正式实现时外部文字需转义，字体与头像由服务准备，HTML 不承担计算或接口访问。

HTML 通过相对路径引用仓库 HarmonyOS 字体。署名由 RenderAttribution 在渲染时统一添加，HTML 源不重复硬编码日期。

## 本轮视觉修订

参考 userinfo 默认主题：暖白底、蓝色重点、玩家 banner 全幅头部、整体渐变遮罩与底边融合，正文保持纯色。周报使用玩家 banner；成绩对比使用共享谱面背景作头部，双方身份区使用纯色，不展示各自 banner。正式渲染失败时，banner 回退用户上传背景，再回退纯色；谱面背景缺失时使用纯色。预览内嵌本地缓存素材，只用于效果展示，与虚构玩家无身份对应关系。

本轮没有修改业务接口。两个正常示例完成真实 PNG 渲染和图片检查；四模式、长文本、空状态仍属于后续模板实现验收。

周报右下为“本周新增 BP”，每条记录左侧显示对应谱面背景，并向右淡出至纯色；仅展示前 3 条时标注总数和展示范围。示例第二条替换为 Ghost Rule，以使用与谱面匹配的背景资源。
