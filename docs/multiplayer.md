# 多人房历史与评分

两个接口返回 1200px 宽 PNG。`theme=default` 使用默认模板：白底、字体层级、细分隔线、红蓝队色与表格，无渐变或数据卡片注释。系统字体优先，非苹果平台回退到现有 HarmonyOS 字体。

```text
GET /multiplayer/history?mp_id=12345&theme=default&page=1
GET /multiplayer/rating?mp_id=12345&theme=default&algorithm=osuplus&page=1
```

沿用服务现有 ApiKey 鉴权。`mp_id` 必须为正整数。成功响应有 `X-Page`、`X-Page-Count`，调用方逐页请求获取完整图片；PNG 页脚也显示页码。不会修改 nonebot 的调用流程，也不会返回图片数组或合并转发消息。

## 历史

先补齐 osu! API 的较早事件，按游戏 ID 去重并按开始时间排序；保持首次响应的时间快照。只显示已结束且有成绩的局，包含零分与失败成绩。每页目标 32 个玩家成绩行，保持单局完整，不截断对局。

展示房间名、比赛时间（UTC+8）、局数、玩家数、团队比分；每局展示谱面、难度、星级、模式、计分方式、结果，以及玩家 Mods、分数、准确率、连击与失败标记。缺失用户或谱面时显示 ID，头像读取失败时显示首字。按该局的分数、准确率或连击计分方式排序和判定团队获胜方；分数列始终显示原始分数。

`team_type` 可筛选 `head-to-head`、`team-vs`、`tag-team-vs` 或 `tag-coop`。合作局不统计胜负，团队平局不增加任何队伍胜场；个人并列第一显示并列结果。

## 评分

每页最多 24 位玩家，按评分降序，相同评分按用户 ID 排序。展示领先玩家、算法、排名、参赛次数、胜率/第一率、胜负平战绩、总分和场均分。历史零分仍显示，评分只纳入非零成绩，不因某一次零分剔除玩家其他成绩。不按常见队伍人数删除人数变化的局。

评分支持按分数计分（Score 或 Score V2）的个人对抗和团队对抗；准确率/连击计分、接力/合作模式返回 400。混合团队模式必须通过 `team_type` 选择，避免合并不同模式的评价基准。换队玩家标为“换队”，逐局按当时队伍统计个人胜负。团队平局计 D；个人并列最高分均计一次第一，第一率以实际非零上场次数为分母。

算法参考 `nonebot_plugin_osubot/draw/rating.py`：

- **osuplus**：`2 / (n + 2) × Σ(个人分数 / 该局平均分)`。
- **bathbot**：`(Σ比值 + 0.5n + 决胜局加成) / n × 1.4^(0.6(n−1)/max(1,G−1)) × (1 + 0.02max(0,m−2))`。`G` 为有效局数，`m` 为玩家使用的不同 Mods 数量。比赛最后一局之前红蓝累计胜场相等且至少各赢一局时，最后一局个人分数与全局平均分之比为决胜局加成。单局参与系数为 1。
- **flashlight**：`平均(个人分数 / 该局分数中位数) × (n / 玩家参赛次数中位数)^(1/3)`。

全部算法使用同一组有效局和非零成绩；修正参考实现中平局记为蓝队获胜、决胜局索引提前一局与单局除零的边界行为。未自动推测暖身局或赛事规则。

## 状态与兼容性

无有效历史、参数不合法、不支持的评分模式或页码越界返回 400；房间不存在返回 404；上游读取或历史分页不完整返回 502；渲染错误返回 500；配额/渲染繁忙继续交给现有全局处理器返回 503。请求取消向上游分页、配额等待和图片渲染传递。

事件 ID（`MatchEvent.Id`、`first_event_id`、`latest_event_id`）及 `before`/`after` 分页游标使用 64 位整数，兼容超过 `Int32.MaxValue` 的历史记录。

修正 `Ossapi.MatchGame.Scores` 为 `List<LegacyScore>`，通过专用转换器兼容 matches API 的旧 `score` 与新 `total_score`，新格式优先取 `total_score`；兼容 acronym 数组及带 `acronym`/`settings` 的 Mods 对象数组。直接使用该库的调用方若引用这一属性，需要同步改用 `LegacyScore.Score`，而不是 `Score.TotalScore`。Mods 解析保留整数和字符串格式，同时支持 acronym 数组与 Mods 对象数组。

## 验证与预览

单元测试覆盖算法基准、单局、平局、零分、个人并列第一、混合模式、分页与决胜局；客户端测试覆盖真实字段形状的 JSON 反序列化。Chromium 集成测试覆盖团队/个人模板、文本转义与页面尺寸。

使用 `MULTIPLAYER_PREVIEW_DIR` 设置目录后运行 `MultiplayerRenderingTests` 可导出团队和个人两种样例 PNG。预览是离线样例，首字头像代表头像不可用时的回退；没有依赖真实房间或线上凭据。
